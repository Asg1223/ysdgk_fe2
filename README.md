# カラーキャッチ！ — Raspberry Pi 3 文化祭ゲーム

緑のマーカーを持って手を振ると、大画面に映った自分の映像の上に出てくる ◯ を「触って」得点する
30秒の体感ゲーム。1人あたり約40秒で回るので行列がさばけて、待っている人も画面を見て楽しめる。

- 入力：USB / Pi カメラ（色マーカー追跡）
- 出力：HDMI モニタ、スピーカー（効果音は起動時に合成するので音源ファイル不要）
- マーカーの色は**緑が既定**。ピンク・青・紫・水色・黄・赤を `K` キーで切替
- スタート方法は3通り：物理ボタン / スペースキー / **マーカーをかざすだけ（部品ゼロ・自動切替）**
- 当日のランキングを自動保存・待機画面に表示

## 1. 用意するもの

| もの | 備考 |
|---|---|
| Raspberry Pi 3 + microSD(8GB以上) | Raspberry Pi OS デスクトップ版 |
| USB カメラ または Pi カメラ | 640x480 で十分。広角だと遊びやすい |
| HDMI モニタ / TV | 大きいほど盛り上がる |
| スピーカー | 3.5mm でもUSBでも可 |
| 緑のマーカー | `marker_card.pdf` を印刷して厚紙に貼る。緑の画用紙や軍手でも可。予備を2〜3枚 |
| （任意）タクトスイッチ + LED + 330Ω抵抗 | **無くても完全に運用できる** → 第5章 |

### 配線（GPIO・BCM番号）※部品がある場合だけ

```
ボタン :  GPIO17 ---- スイッチ ---- GND      （内部プルアップを使うので抵抗不要）
LED    :  GPIO27 ---- 330Ω ---- LED(+) ... LED(-) ---- GND
```

ピン番号を変えたいときは `config.json` の `gpio.button_pin` / `gpio.led_pin`。

## 2. インストール

```bash
unzip colorcatch.zip && cd colorcatch
chmod +x *.sh           # ← 「権限がありません」対策。最初に1回だけ
./setup.sh              # USBカメラのとき
./setup.sh --picamera   # Piカメラ(リボンケーブル)のとき
```

`setup.sh` は apt から OpenCV / pygame を入れる（pip でビルドすると Pi 3 では数十分かかる）。
最後に自己テストが走り、`結果: OK` が出れば準備完了。

**「Permission denied / 権限がありません」と出たら**
zip を Windows・Mac や USB メモリ経由で展開すると実行権限が外れます。上の `chmod +x *.sh` で直ります。
それでもダメなとき（FAT/exFAT の USB メモリ上など）は、頭に `bash` を付ければそのまま動きます:

```bash
bash setup.sh
bash run.sh
python3 main.py         # run.sh を使わず直接起動してもよい
```

`tar.gz` 版を Pi 上で `tar xzf colorcatch.tar.gz` すれば権限は保たれます。

## 3. 起動と操作

```bash
./run.sh                  # 本番（フルスクリーン）
./run.sh --windowed       # ウィンドウ表示
./run.sh --no-camera      # カメラなし、マウスで動作確認
./run.sh --debug          # FPS とマスク画像を表示
./run.sh --calibrate      # 色あわせ画面から起動
python3 selftest.py       # 画面なしの動作テスト
```

| キー | 動作 |
|---|---|
| スペース / Enter / 物理ボタン | スタート・次へ |
| C | 色あわせ（キャリブレーション）画面 |
| K | マーカーの色を変える（緑→ピンク→青…） |
| D | デバッグ表示の切替 |
| `[` `]` | 色の許容幅を狭める / 広げる |
| `-` `=` | 明るさしきい値を下げる / 上げる |
| ESC / Q | 終了（色あわせ画面では戻る） |

## 4. マーカーの色（既定は緑）

反応する色は `config.json` の `marker.color`。既定は **`green`（緑）** です。
ゲーム中に **`K` キー**を押すと下の色を順番に切り替えられ、選んだ色は `config.json` に保存されます。

| 名前 | 色 | 色相(H) | 教室での注意 |
|---|---|---|---|
| `green` | 緑（既定） | 60 | **黒板が緑**。下記の対策済みだが、黒板に強い光が当たる配置は避ける |
| `pink` | ピンク | 165 | 教室にほぼ無い色。いちばん安全 |
| `blue` | 青 | 108 | ジーンズ・制服・青いファイルに反応することがある |
| `purple` | 紫 | 140 | 少ないが、暗いと青と紛れる |
| `cyan` | 水色 | 90 | 窓の外の空に注意 |
| `yellow` | 黄 | 28 | 肌色に近いので、手が写ると誤検出しやすい |
| `red` | 赤 | 0 | 赤い服・掲示物が多い教室では不利 |

### 黒板対策について

緑は黒板と同じ色相帯（H≈60-72）に入りますが、**黒板は暗く**（明度 V≈79）、
緑の画用紙や軍手は明るい（V≈150-190）ので、緑プリセットだけ
`sat_min=120 / val_min=120` と高めにして分離しています。自己テスト [6] で
「黒板」「黒板の照り返し」「観葉植物」「木の机」「肌色」がすべて無視されることを確認済みです。

それでも心配なときは、黒板をカメラの画角から外す（カメラを少し下向きに）か、
`K` キーで **ピンク** に逃げてください。ピンクは教室にほぼ存在しない色なので最も安定します。

### 印刷用マーカーを作り直す

```bash
python3 make_marker_card.py                # config.json の色（既定は緑）で作る
python3 make_marker_card.py --color pink   # 色を指定
python3 make_marker_card.py --all          # 全7色を1つのPDFに
```

`marker_card_allcolors.pdf` は全色入りなので、当日どの色が安定するか試すのに使えます。

## 5. GPIO部品が無い場合

ボタンもLEDも無くて構いません。**GPIOが使えないと自動で「かざしてスタート」に切り替わります。**

### A. かざしてスタート（推奨・部品ゼロ）

待機画面の左に ◎ の的が出ます。来場者がマーカーをそこに **1.8秒重ねる**と、
リングが金色に溜まりきってゲームが始まります。結果画面も同じ的で「もう一度」。
**係の人が何も操作しなくても勝手に回り続ける**ので、むしろボタンより運営が楽です。

- 待ち時間は `config.json` の `input.hold_seconds`（短いと誤爆、長いと待たされる。1.5〜2.5 が目安）
- ボタンを付けた状態でも両方使いたいなら `input.always_show` を `true` に
- 切りたいときは `input.hold_to_start` を `false`（キーボード運用になります）

### B. キーボードのスペースキー

USBキーボードを台に置き、係の人がスペースを押す。お菓子の箱に穴を開けて
キーボードを隠し、スペースキーの上にペットボトルのキャップを貼ると、それらしい大きなボタンになります。

### C. 100円ショップのBluetoothシャッターリモコン

スマホ用の自撮りリモコンはキーボードとして認識されるものが多く、ペアリングするだけで
スペース/Enter が飛びます（機種により Volume キーのこともあるので事前確認を）。
ワイヤレスプレゼンターや USB マウスでも代用できます（クリックでスタート）。

### LEDの代わり

LEDが無くても、待機中は「かざしてスタート」の点滅、プレイ中は残り時間バーが画面に出るので
状態は見て分かります。**電子部品はひとつも要りません。**

## 6. 色あわせ（当日いちばん大事）

会場の照明は教室とちがうので、**設営したら必ず 1 回やる**。

1. `C` キーで色あわせ画面
2. 画面中央の黄色い枠にマーカーを入れる（画面いっぱいでなく、枠を埋める程度）
3. ボタン（またはスペース）を押す → 「色を登録しました」と出れば成功
4. 右下のマスク画像で、マーカーだけが白くなっているか確認
   - 白い部分が広すぎる → `[` で許容幅を狭める
   - マーカーが写らない → `-` でしきい値を下げる、または照明を当てる
5. 設定は `config.json` に自動保存されるので、次の起動から有効

窓際で日が傾くと色が変わる。**昼と午後で 1 回ずつやり直す**と安定する。
プリセットの色に戻したいときは `K` キーを押せば、登録した色より優先されます。

## 7. 当日の運営

- 想定回転率：1人 40〜50 秒（説明10秒＋カウント4秒＋本編30秒＋結果）→ **1時間で約70〜80人**
- 立ち位置にビニールテープで印をつける（カメラから1.5〜2m）。近すぎると手が画面外に出る
- 係は2人：①受付・マーカー渡し ②スタートボタンと呼び込み
- マーカーは2枚以上用意（渡す用と戻ってくる用で回す）
- ランキングは `scores.json` に保存される。日付ごとに集計されるので当日分だけが表示される
- 表彰したいときは終了後に `python3 -c "import json;d=json.load(open('scores.json'));print(sorted(d,key=lambda r:-r['score'])[:10])"`

## 8. 調整（config.json）

| 項目 | 意味 | 迷ったら |
|---|---|---|
| `marker.color` | マーカーの色（`green`/`pink`/`blue`…） | 黒板が写るならピンク |
| `game.duration` | 制限時間(秒) | 行列が長い日は 20 に |
| `game.spawn_interval_start/end` | 出現間隔(秒)。end に向かって速くなる | 小さいほど難しい |
| `game.bomb_rate` / `bonus_rate` | ✖ と ★ の出現率 | 小さい子が多いなら bomb を 0.10 に |
| `input.hold_seconds` | かざしてスタートの秒数 | 1.5〜2.5 |
| `marker.cursor_radius` | 当たり判定の広さ(px) | 当たらないと言われたら 60 へ |
| `marker.min_area` | この面積未満は無視 | 誤検出が多いなら大きく |
| `screen.width/height` | 解像度 | Pi 3 では 1280x720 まで |
| `camera.width/height` | 処理解像度 | 上げると重くなる。320x240 推奨 |

## 9. 困ったとき

| 症状 | 対処 |
|---|---|
| カーソルが出ない | `D` でマスク確認 → 色あわせやり直し。蛍光灯の反射で白飛びしていないか |
| 黒板や掲示物に反応する | `K` でピンクに変える。または黒板を画角から外す |
| カーソルが他の物に飛ぶ | 背景に同じ色の物がある。机に布をかける／`[` で許容幅を狭める |
| 左右が逆 | `config.json` の `camera.mirror` を切り替える |
| 音が出ない | `amixer cset numid=3 1`（3.5mm出力に固定）／`config.json` の `audio.enabled` |
| 画面が暗くなる | `./install_autostart.sh` を実行（スクリーンセーバー停止も入る） |
| 動きがカクつく | `screen` を 1280x720 → 800x480 に、`camera` は 320x240 のままで |
| `./run.sh: Permission denied` | `chmod +x *.sh`、または `bash run.sh` / `python3 main.py` |
| `bad interpreter: ^M` | Windowsの改行が混ざっている → `sed -i 's/\r$//' *.sh` |
| ボタンが効かない | 配線を確認。キーボードのスペース、または第5章の「かざしてスタート」で運営できる |
| 勝手にゲームが始まる | `input.hold_seconds` を伸ばす。◎の位置に人が立たない導線にする |

## 10. 発展ネタ（時間があれば）

- 2人対戦：色ちがいのマーカー（緑とピンクなど）を2つ追跡して左右で得点を競う（`ColorTracker` をもう1つ作る）
- 効果音を差し替える：`colorcatch/sound.py` の `_build()` に波形を足す
- スコアを Web で表示：`scores.json` を `python3 -m http.server` で公開して廊下のモニタに出す
- 難易度選択：待機画面でボタン長押し → こどもモード（時間45秒・爆弾なし）

```
run.sh / setup.sh / install_autostart.sh
make_marker_card.py  印刷用マーカーを色ごとに作るスクリプト
marker_card.pdf      印刷用マーカー（緑）
colorcatch/
  app.py       画面・入力・状態遷移
  engine.py    ゲームロジック（描画非依存・テスト対象）
  tracker.py   カメラと色マーカー追跡

  sound.py     効果音の合成
  ranking.py   スコア保存
  text.py      文言とフォント（日本語フォントが無ければ英語表示）
  config.py    設定の読み書き
```
